# Informe: cómo se arma el PDF

Cada integrante escribe su sección en `secciones/` (en Markdown, para que quede su commit). Al final, Victor las une en un
documento de Word o Google Docs, inserta las imágenes de `evidencias/` y `evaluacion/resultados/`, y exporta a PDF con
el nombre exacto:

**`informe/Informe-modelo-rag-BarberForge.pdf`**

| Sección | Archivo | Responsable |
|---|---|---|
| A. Portada · B. Índice · C. Introducción · D. Problema | `secciones/A-B-C-D.md` | Victor |
| E. Definición del modelo | `secciones/E-definicion-del-modelo.md` | Eli |
| F. Implementación y pruebas (interfaz) | `secciones/F1-pruebas-interfaz.md` | Miyer |
| F. Implementación y pruebas (API y Golden Dataset) | `secciones/F2-pruebas-api-y-resultados.md` | Javier |
| G. Conclusiones y trabajos futuros | `secciones/G-conclusiones.md` | Victor (con un aporte de cada uno) |

Consejos para el PDF: título de cada sección con estilo «Título 1» (así Word arma el índice solo: Referencias →
Tabla de contenido), imágenes con pie de figura («Figura 3. Configuración de documentos en OpenWebUI») y tablas con
el mismo formato.
